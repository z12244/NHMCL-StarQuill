# 0.8.2 更新说明

已移除内存优化中的隐藏 PowerShell / 编码脚本执行，旧内存优化开关暂时停用。没有添加白名单、关闭杀毒软件或申请管理员权限。未取得代码签名证书，也未在火绒环境实测，不能保证所有安全软件均无提示。

EXE 同目录使用 .starquill-profile 保存配置和账号，.minecraft 保存游戏。只复制 EXE 到新的空目录会重新初始化；已有 .minecraft 时直接使用。不会自动导入旧的全局账号或配置。移动整个目录则会携带目录内的档案；账号加密信息跨电脑可能需要重新登录。目录需有写入权限。

异常退出后通过 Windows wevtutil 只读查询当前运行时间范围内的应用错误事件，按游戏 PID 精确匹配，将可用记录放入 windows-events.xml。没有权限、尚未写入或没有匹配事件都会明确说明，不视为系统没有故障的证据。没有生成的 JVM 堆栈仍无法恢复。资源加载报错不等于已确认退出原因。

全量自动化测试 66 项通过；基础语法、打包源码一致性及 PID 筛选检查通过。实际整合包复现、桌面交互和火绒验证受当前环境限制，尚未完成，不能称为完整实机深度测试。

事件读取接口参考：https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/wevtutil
