# 版本设置 · 0.7.0

在「我的版本」的每一行点击 **版本设置**。可管理本启动器和 PCL / HMCL 等启动器放在标准 `.minecraft/versions` 目录中的有效版本。

## 启动与隔离

- 显示名称：修改启动器版本列表的名称，原文件夹名称、JSON 与继承关系保持兼容。
- 内存：跟随全局设置，或为此版本单独分配。上限来自当前系统物理内存。
- Java：跟随全局、自动匹配、手动指定；手动模式可选择已扫描的 Java 或浏览 `java.exe`。
- 隔离：跟随全局、单独隔离或共享根目录。本启动器创建的模组版本和整合包继续固定隔离。

点击「保存此版本设置」后生效。独立设置保存在 `versions/版本名/.starquill-settings.json`，不会改写其他启动器的设置。其他启动器可以使用同一游戏目录，但未必读取星翎的独立 Java / 内存选项。切换隔离不会自动搬移存档和模组，保存后再到资源管理页查看实际目录。

## 高级设置

全局进入「启动设置 → 高级设置」。版本进入「我的版本 → 版本设置 → 启动与隔离 → 高级设置」。版本中的每一项可独立跟随全局，也可明确留空、开启或关闭。

Java 虚拟机参数在游戏主类之前传入。游戏参数在主类之后传入，含空格的值可用引号括起。内存管理支持 Java 默认、G1、Parallel、Serial 和 ZGC。Windows 上 Java 8–18 默认使用 Java Launch Wrapper 处理参数编码，Java 25+ 搭配 LWJGL 3.4.0 或 3.4.1 时默认加载 LWJGL Unsafe Agent。

启动前命令在本次游戏目录中执行。命令返回 0 后启动 Java，可引用 `%STARQUILL_GAME_DIR%`、`%STARQUILL_ROOT%`、`%STARQUILL_JAVA%`、`%STARQUILL_VERSION%`。版本自定义的 JVM 参数与启动前命令保存在当前启动器的本地档案中，离线版本包只传递其他高级选项。

勾选高性能显卡会为本次选定的 Java 向 Windows 请求高性能 GPU，实际选择取决于系统与驱动。勾选禁止更新模组会阻止工坊替换已安装的模组。跳过本地文件校验只影响启动时复用已有文件，所有新下载文件仍执行长度和哈希校验。

## 模组与资源管理

选择「模组与资源管理」，可切换 Mods、资源包、光影。

- 读取现有文件，不要求先通过星翎安装。模组读取常见 Fabric、Forge、NeoForge 的名称、ID 和版本信息；无法识别时仍显示文件名。
- 搜索本地中文名、文件名、模组 ID。
- 单独或批量启用 / 禁用。禁用使用 `原文件.jar.disabled` / `原文件.zip.disabled`，启用恢复原后缀。不会修改 JAR 内容。
- 导入本地 JAR / ZIP，可多选，保留原文件；同名或相同模组 ID 的资源会提示先处理已有版本。
- 移除放入 `.minecraft/.starquill/content-trash/独立编号/`，本次页面会话可逐项撤销。重开启动器后仍可从回收区手动取回原文件，`record.json` 记录原目录。
- 「去资源工坊下载」自动带上当前版本与内容分类。
- 打开实际游戏目录、模组配置、世界存档和游戏截图目录。

管理结果在下一次启动游戏时生效；运行游戏或进行安装任务期间禁用修改。共享目录中的修改也会影响使用该目录的其他版本。资源包和光影恢复文件后仍需在游戏内选择启用。

禁用或移除某个模组时不会自动修改其他依赖它的模组；缺少必需前置可能导致游戏无法启动。工坊会保留禁用状态，下载同一模组的新版本前会提示先启用或移除它。
